# Validation Plan

The public v0.1 repository validates software behaviour, not automotive serviceability.

## Phase 1 — Software verification
- schema validation
- feature extraction tests
- reference comparison tests
- confidence logic tests
- classification tests
- report generation tests

## Phase 2 — Bench repeatability
For one selected alternator family: repeated mounting tests, repeated speed/load cycles, sensor repeatability, fixture repeatability, and operator repeatability.

## Phase 3 — Known-condition study
Create verified populations including healthy reference units, selected known degradation states, failed units, and repaired/remanufactured units where appropriate.

## Phase 4 — Baseline comparison
Compare ComponentLife outputs with conventional functional test results, specialist bench results, engineering inspection, and teardown evidence where available.

## Phase 5 — Field validation
Track selected assessed components after installation and record installation, operating duration, warranty event, removal, confirmed failure, and inspection finding.

Only after sufficient field evidence should remaining-serviceability modelling be investigated.

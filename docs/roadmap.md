# Product Roadmap

## v0.1 — Degradation Fingerprint & Confidence Engine
CSV ingestion, engineering feature extraction, demo reference comparison, anomaly detection, degradation fingerprint, confidence output, condition report, dashboard.

## v0.2 — Adaptive Test Recommendation Engine
Use detected anomalies and uncertainty to recommend the next controlled test region.

## v0.3 — Physical Bench Integration
Live data acquisition, protocol control, sensor health, calibration records, component identification, and safety-state handling.

## v0.4 — Physics-Informed Machine Learning
Component-family models, engineering constraints, calibrated uncertainty, and independent validation.

## v0.5 — ComponentLife Passport
Persistent component ID, test history, protocol version, condition records, and later field outcomes.

## v1.0 — Commercial Alternator Platform
Release only after appropriate engineering validation, customer pilots, quality procedures, safety review, legal/product-liability review, and data-governance controls.

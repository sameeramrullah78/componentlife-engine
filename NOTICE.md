# ComponentLife IP Notice

This repository is a **demonstration implementation** of the ComponentLife Degradation Fingerprint & Confidence Engine.

The following are intentionally excluded from the public demonstrator:

- validated commercial degradation thresholds;
- real recycler or customer datasets;
- real field-outcome datasets;
- production model weights;
- proprietary adaptive-test rules;
- production calibration procedures;
- production sensor specifications;
- confidential customer integrations;
- validated remaining-serviceability models.

The CSV files under `data/` are synthetic and are not evidence of real component performance.

The public repository demonstrates software architecture and analytical flow; it does not disclose the future commercial knowledge base intended to form part of ComponentLife's competitive advantage.

# Security Policy

## Supported version

Only the latest `main` branch is supported during the proof-of-concept phase.

## Sensitive data

Do **not** commit customer names, vehicle-owner data, VIN-linked personal data, real warranty records, confidential recycler data, API keys, production credentials, private reference datasets, or proprietary model files.

Use environment variables or a secret manager for credentials.

## Reporting a vulnerability

Report vulnerabilities privately to the repository owner rather than opening a public issue containing exploit details.

## Automotive safety

This repository is not a safety-certified automotive diagnostic system. Outputs must not be used as the sole basis for declaring a component safe, roadworthy, certified, or guaranteed for a particular remaining service life.
